# v0.5.2 - Documentation in English

**Date:** 2026-09-28

## Goal

Make the repository readable for anyone who lands on it, and tolerate a flaky
network during the first deployment.

## Changes Made

### Documentation

- Translated every document to English and renamed the files accordingly.
- Restructured the README around the architecture diagram, and stated the
  10-20 minute first-boot cost up front instead of letting it surprise people.
- Added `CONTRIBUTING.md`, issue templates and the license.

### Network Tolerance

- The Ollama model preload no longer aborted the pod on a failed pull.
- Raised the LiteLLM bootstrap Job `backoffLimit` from 3 to 10, so a slow
  gateway start does not burn the hook.

## Correction

Making the preload tolerant treated the symptom. The pulls were failing because
Ollama's own NetworkPolicy denied egress to the model registry, and swallowing
the error produced a pod that reported Ready with no weights - surfacing later
as a 500 from the gateway. Root cause fixed in v0.5.5.
