# v0.5.0 - Complete Observability

**Date:** 2026-09-24

## Goal

Complete the observability stack with distributed tracing and improved metrics for
External Secrets Operator.

## Changes Made

### Tempo as Trace Backend

Added Tempo as distributed tracing backend to complete observability:

- **Installation:** Tempo chart v1.11.0 in wave -10
- **Configuration:** Local storage for traces (24h retention)
- **Ingestion:** OTLP gRPC and HTTP support
- **Metrics:** Service-graphs and span-metrics enabled

**Before:** Traces went to the OTel collector's `debug` exporter (didn't persist).
**Now:** Traces are stored in Tempo and can be queried in Grafana.

### OTel Collector Integration

Updated OTel collector to send traces to Tempo:

- **Exporter:** Changed from `debug` to `otlp` pointing to Tempo
- **Endpoint:** `tempo-distributor.nullnode-observability.svc.cluster.local:4317`
- **Protocol:** OTLP gRPC with insecure TLS (local)
- **Pipeline:** traces → [memory_limiter, batch] → [spanmetrics, otlp]

### Grafana Integration

Configured Tempo as datasource in Grafana:

- **Datasource:** Tempo added as traces datasource
- **URL:** `http://tempo-query.nullnode-observability.svc.cluster.local:3100`
- **Access:** Proxy (within cluster)
- **Discovery:** Grafana sidecar auto-discovers

### Traces Dashboard

Created traces dashboard in Grafana:

- **Name:** "NullNode Traces"
- **Viewer:** Tempo trace viewer integrated
- **Query:** TraceQL for all recent traces
- **Refresh:** 10s
- **Scope:** All cluster traces

### External Secrets Operator Dashboard

Created specific dashboard for External Secrets Operator:

- **Secret Sync Duration:** Secret synchronization time
- **Secret Sync Errors:** Accumulated sync errors
- **Secret Requests:** Total secret requests
- **Cache Performance:** Cache hits vs misses

**Metrics:**

- `external_secrets_secret_sync_duration_seconds`
- `external_secrets_secret_errors_total`
- `external_secrets_secret_requests_total`
- `external_secrets_secret_cache_hits_total`
- `external_secrets_secret_cache_misses_total`

### External Secrets Operator Alerts

Configured Prometheus alerts for External Secrets monitoring:

- **ExternalSecretsHighErrorRate:** Error rate > 0.1/sec for 5m (warning)
- **ExternalSecretsSyncFailure:** Sync errors > 0 for 10m (critical)
- **ExternalSecretsHighLatency:** p95 latency > 30s for 10m (warning)
- **ExternalSecretsCacheLowHitRate:** Hit rate < 50% for 15m (info)
